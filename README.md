WLSM - WildLife Scene Manager
A small Windows launcher for installing and managing WildLife scene/map saves.

Features
Install scene .wlsave files manually or by drag and drop
Automatically detects the scene map from the JSON level value
Places scene saves in the correct MySaves map folder
View scene previews in the correct 3:2 format
Search, sort, and filter scenes by map
Delete scenes to the Recycle Bin
Open scene CustomAssets folders when available
Clear orphan CustomAssets folders while protecting MySaves and Collections
Blocks unsupported character/prop saves
Custom icons and dark blue UI
